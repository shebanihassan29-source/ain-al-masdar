# عين المصدر (Ain Al-Masdar)

منصة بحث أكاديمي موحّدة — بحث واحد يغطّي OpenAlex وCrossref وSemantic Scholar وPubMed وarXiv وDOAJ وCORE، مع أدوات تصدير وتحليل واستيراد جاهزة للباحث العربي.

**فكرة وتصميم: د. حسن الشيباني**
مركز التعليم الإلكتروني — جامعة الزاوية

## المزايا
- بحث موحّد عبر 7 قواعد بيانات أكاديمية دولية في آن واحد.
- بحث ذكي ثنائي اللغة (توسيع الاستعلام العربي تلقائياً بمكافئه الإنجليزي عبر الذكاء الاصطناعي).
- فلاتر: وصول مفتوح، PDF متاح، مقالات محكّمة فقط، الجامعات الليبية فقط.
- تنبيه فوري للأبحاث المسحوبة (Retracted) والنسخ الأولية (Preprints).
- سحابة مفاهيم متقاطعة (Concepts) ولوحة تحليلات بصرية (توزيع سنوي، أكثر الباحثين والمجلات).
- تصدير بصيغ Word وPDF وRIS وBibTeX وCSV وJSON، أو حزمة ZIP جاهزة للاستيراد المباشر في EndNote وZotero وMendeley.
- "مكتبتي": مجموعات محفوظات دائمة مع ملاحظات AI توليدية لكل مرجع.
- استيراد بالجملة عبر قائمة DOIs.
- مساعد بحثي بالذكاء الاصطناعي (مقدمات، ملخصات، فجوات بحثية، أفضل المصادر).
- يعمل كملف واحد (Single-File) بدون أي خادم — يكفي فتحه في المتصفح.

## التشغيل
هذا الموقع ملف HTML واحد (`index.html`) يعمل بالكامل من طرف المتصفح، بدون خادم أو تثبيت.

- **محلياً:** نزّل `index.html` وافتحه في أي متصفح حديث (يتطلب اتصالاً بالإنترنت لجلب النتائج من القواعد العلمية).
- **عبر GitHub Pages:** فعّل GitHub Pages لهذا المستودع (Settings → Pages → Branch: main → مجلد الجذر) وستحصل على رابط مباشر للمنصة.

## مفتاح الذكاء الاصطناعي (اختياري)
لتفعيل ميزات الذكاء الاصطناعي (الترجمة التلقائية للاستعلام، الملخصات، ملاحظات المكتبة)، أضف مفتاح API متوافق مع OpenAI من قائمة "⚙️ الإعدادات" داخل المنصة. يُخزَّن المفتاح محلياً في متصفحك فقط ولا يُرسل لأي خادم تابع للمنصة.
